The taxreport pair carries ~10 prose em dashes each — the densest cluster in the funnel. Rule to apply funnel-wide: **zero em dashes in prose** (testimonial quotes and numeric ranges stay untouched).

**taxreport.html + taxreportvip.html:**

- "strategies—but your CPA only uses the same dozen every year." → "strategies. But your CPA only uses the same dozen every year."
  
- "Most CPAs are reactive—they file based on what happened. This report is PROACTIVE—it shows…" → "Most CPAs are reactive. They file based on what happened. This report is PROACTIVE: it shows…"
  
- "apply to YOUR situation—and calculates your savings potential." → "…situation, and calculates your savings potential."
  
- "classifies it as "non-passive"—letting you deduct" → "classifies it as "non-passive," letting you deduct"
  
- "for your situation—or you're unsatisfied for any reason—email us" → commas both sides
